# Search Users App

## Описание
Это простое приложение на React и TypeScript, которое позволяет искать пользователей по имени и фильтровать их результаты в реальном времени.

## Технологии
- **React**: библиотека для создания пользовательских интерфейсов.
- **TypeScript**: для строгой типизации и безопасной работы с данными.
- **Vite**: инструмент для быстрого сборки и запуска приложения.

## Запуск проекта
1. Установите зависимости:
   ```bash
   npm install

1. Запустите проект:
   ```bash
   npm run dev
